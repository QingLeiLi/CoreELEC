# 本地材料使用说明

材料已实际复制到本目录下`本地刷机材料/`，原文件保留。合计约5.38GiB；镜像只保留本机成功使用的Android和Armbian，没有CoreELEC实验镜像。

|目录|内容|
|---|---|
|01-Android|成功底包归档、解出的E900V22E-YYFROM.img、原包license、固件原说明|
|02-工具|成功使用的Term-1.0.70.apk、本机Mac platform-tools 37.0.2（无ADB私钥）、Android包内配套USB_Burning_Tool_v2.1.2.zip|
|03-Armbian|本机已启动的Armbian 26.05.0 / s905l3b-e900v22e / 6.18.26镜像，提供.img与.img.gz|

Windows线刷导入01-Android/E900V22E-YYFROM.img；U盘写入03-Armbian中的.img。Mac ADB可使用02-工具/Mac-platform-tools-37.0.2/adb，整个platform-tools目录一起保留以包含动态库。

重要界限：USB Burning Tool 2.1.2是成功Android原包附带的配套版本，**最后一次实际成功烧录所用工具版本未留完整记录**，不把它虚称成已单独验证。license是第三方底包自带资料，给下一台用之前核对自己的MAC；不要直接沿用包内身份数据。平台工具只适用于Mac，不是Windows版。

Rufus本地原安装包未找到，本次没有把新下载/未经本机使用的版本加入已用工具目录。Windows需要自行准备写盘工具，按原镜像方式写整盘。

`材料清单.json`是版本化目录/大小/哈希索引；本地材料中的`文件清单.json`附原始来源，`SHA256SUMS`可用于复制后校验。大文件与license不进入Git，复制给另一台电脑时要连同`本地刷机材料/`一起复制，单独clone仓库不会带这些二进制文件。
