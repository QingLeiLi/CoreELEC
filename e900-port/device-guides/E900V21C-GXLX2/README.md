## 最短成功路径

核对板号与GXLX2/P291/1GB → Windows晶晨工具将对应YYF Android 4.4.2线刷到eMMC → HDMI/有线网启动 → 小白文件管理器开FTP、上传并安装终端APK → 本机终端取得su、启用/重启adbd → Mac确认root ADB → 制作对应Armbian U盘并从update入口运行其引导脚本 → 确认USB启动和有线SSH。此后再选择是否进入本项目的CoreELEC实验。

本档案中的历史IP `.59`（Android）、`.38`（早期Armbian）、`.11`（后期CoreELEC）只作证据定位；下一台请用路由器实际租约。不得复制本机MAC、Android身份、SSH密钥、ADB密钥或USB root UUID。

## 记录边界

底包身份、内核输出、FTP入口和恢复后root ADB有材料支撑。最终成功烧录那次的工具版本/勾选截图、第一次终端输入的逐条命令没有完整留档：下面分别标明“包内说明”或“复用操作单”，不冒充原始操作录像。原厂系统与后来刷入的YYF第三方底包是两套系统。
